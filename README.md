# Outlook Add to To Do - Stage 1

This is the authentication and Microsoft To Do default-list test for the planned Outlook add-in.

## Deploy to GitHub Pages

Upload all files in this folder to the root of the `outlook-add-to-todo` repository. In repository Settings > Pages, set **Deploy from a branch**, branch **main**, folder **/(root)**.

Open: https://stanleyhouse909.github.io/outlook-add-to-todo/auth.html

Select **Sign in and test access**. This stage only lists To Do lists and identifies the built-in default list. It does not create, update, or delete tasks.
